# 线索项目重要度打分模型（v0.2 公开版）

输出 1–5 星映射到表单"项目重要性"列。四因子，各因子先打 1–5 分，加权后
四舍五入到最近 0.5 分再映射星级。**企业自报营收/税收不参与打分**（口径决定：
自报数可信度低），仅作背景；与主体分量失配（如注册 100 万新设企业自报次年营收
数千万）时输出"数据存疑提示"。

## 因子一：赛道契合度（权重 35%）

| 得分 | 标准 |
|---|---|
| 5 | S3 关联度 A（主营即金融业务，或以金融机构为核心客户） |
| 4 | 关联度 B，且命中本地台账薄弱赛道（单赛道 <15 家，参照汇总表分布） |
| 3 | 关联度 B（通用能力已有金融落地） |
| 2 | 关联度 C（概念沾边，无实质金融业务/客户） |
| 1 | 关联度 D（非金科）——同时触发 D 档警示 |

主赛道属本地台账空白类（如另类投资/数字资产管理/密码技术）且关联度 ≥B → +0.5。

## 因子二：主体分量（权重 25%）——只用可核硬信息

| 得分 | 标准 |
|---|---|
| 5 | 金融牌照主体（支付/理财子/保险等持牌），或注册资本 ≥10 亿且实体运营 |
| 4 | 注册资本 1–10 亿，或 国家级资质（高新+专精特新小巨人/单项冠军） |
| 3 | 注册资本 1000 万–1 亿，或 省市级资质（专精特新、高新） |
| 2 | 注册资本 100 万–1000 万的成长型/新设企业 |
| 1 | 注册资本 <100 万且无资质，或纯空壳特征（集中登记地+无实缴迹象） |

## 因子三：背景与落地性（权重 25%）

| 得分 | 标准 |
|---|---|
| 5 | 双落地已完成，或集团正式批示迁移（有会议/文件节点） |
| 4 | 实质推进：已多轮会面+企业明确迁址意向+难点有解 |
| 3 | 已建立对接（≥1 次正式会面），意向口头积极 |
| 2 | 仅线索接触/参加活动，意向未确认 |
| 1 | 无线索来源记录或企业回避 |

加分：央企/头部战投/知名基金背景 +0.5（封顶 5）。仅名称模式落地性无信息 →
按中性 3 分并注明"落地性信息待补充"。

## 因子四：战略稀缺性（权重 15%）

| 得分 | 标准 |
|---|---|
| 5 | 填补本地 22 类台账空白，或金融基础设施/要素市场关联载体 |
| 4 | 命中台账薄弱赛道（<15 家）且为赛道内头部/特色主体 |
| 3 | 赛道内有差异化能力（技术代差、稀缺牌照、独特场景） |
| 2 | 同质化主体（台账内已有 ≥30 家同类） |
| 1 | 与金融科技集聚带战略无关联点 |

## 星级映射

加权总分 → 星级：≥4.25=★★★★★；3.5–4.24=★★★★；2.75–3.49=★★★☆；
2.0–2.74=★★★；1.25–1.99=★★；<1.25=★。

## 校准闭环（必填）

每月将"AI 星级 vs 人工终判"不一致案例追加 calibration.md（企业、AI 分、
人工分、差异原因），累计 ≥5 例后回顾调整分档表；调整须用户确认。
