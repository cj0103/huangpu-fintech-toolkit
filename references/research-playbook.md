# 企业信息卡搜集手册（包内自包含，禁止外引其他 skill）

目标：为每家企业产出一张可溯源的信息卡。**信息卡是 S3 判定与 S5 成稿的唯一事实来源。**

## 信息卡固定 schema

```yaml
企业名:            # 工商全称（S1 消歧确认）
候选消歧记录:      # 简称输入时列过的候选与确认方式
工商基本面:        # 注册资本/币种、成立时间、注册与办公地址（到楼宇）、
                   # 法定代表人、股权结构（实控人/国资/外资背景）、分支机构
许可与资质:        # 金融类牌照（支付/征信/代销等）、高新、专精特新、ICP 等；
                   # 每项标注认定主体与年度
产品与业务:        # 主营产品线、技术路线、盈利模式；以官网/年报自述为准，
                   # 摘录原文短句（供 S3 引用原句、S5 句式改写）
金融证据:          # 金融客户与场景证据，分三档：
  一档_基础设施与要素市场:   # 上交所/票交所/清算机构/大型银行总行级等
  二档_持牌金融机构:         # 银行、券商、保险、基金、消金等
  三档_泛企业客户:           # 非金融客户（用于判"通用技术"降档）
关联公司:          # 母公司/子公司/同系企业；持牌或标杆主体标注为[关联锚点]
风险筛查:          # 见下方专项；无则写"公开信息未见重大风险事项"
动态:              # 近12个月：融资/中标/新品/迁址/涉诉（时间+来源）
来源清单:          # 每条事实 → URL/材料名+定位 + 采集日期 + 三档标注
信息截至:          # YYYY-MM-DD
```

## 搜集清单（固定动作，防止搜两下就交差）

按来源优先级逐层执行，每层搜不到的字段标 ❓ 进入下一层，不硬凑：

1. **填报材料原文**（表单模式时优先级最高）：企业介绍、附件 docx/ppt/pdf；
2. **企业官方**：官网产品页/关于我们、年报/招股书/白皮书（用 WebSearch 定位
   官网，WebFetch 抓页面；查不到官网降级）；
3. **监管与协会公示**（金融科技专项必查清单，命中即硬证据 ✅）：
   - 中国人民银行 支付业务许可证 公示（已许可机构名单，判断支付类及牌照状态）
   - 中国支付清算协会 会员/备案公示
   - 中国互联网金融协会 会员名单
   - 上海金融科技产业联盟 成员名单
   - 国家高新技术企业名单（科技部火炬中心/上海市科委公示）
   - 专精特新"小巨人"公示（工信部及上海市经信委）
   - 央行征信机构备案、个人征信名单；基金销售/代销机构公示（证监会/中基协）
   - 上海数据交易所 挂牌数据产品/会员公示（数据要素类企业）
4. **主流财经媒体**：36氪/财新/界面/证券时报等对企业业务的报道（⚠️ 单一来源须交叉）；
5. **企业信息平台**（企查查/爱企查/天眼查页面，经 WebSearch 摘要获取）：只用于
   工商信息与股权，业务表述不用其"AI 简介"；
6. **命中 taxonomy.md 标志性企业锚点**：企业即锚点本身时，直接引用包内已知
   事实并标注【图谱】来源。

## 风险筛查专项（每项必查，命中单列标红）

- 经营范围/业务含：虚拟货币、稳定币、ICO、场外配资、P2P 网络借贷遗留；
- 信用中国 / 国家企业信用信息公示系统：行政处罚、经营异常、严重违法名单；
- 重大涉诉与被执行记录（信息摘要级即可）；
- A07 数字资产管理类目专用：境内实质开展虚拟货币业务 → 直接按 taxonomy.md
  A07 监管提示标红，不进入常规推荐流程。

## 搜集深度分档

| 模式 | 动作 |
|---|---|
| 标准 | 清单 1–5 全跑 + 风险全查（线索表企业、仅名称模式默认） |
| 快模式 | 1–3 层 + 支付/协会两项 + 风险仅信用公示；字段查不到即 ❓ 不深挖 |
| 全库复核 | 不调研，仅用表内已有文本 + 包内锚点跑 S3（汇总表批量场景） |

## 批量作业纪律（表单模式 17~400 行）

- 逐企完成信息卡再做下一家；中途不断言未调研企业；
- 同名/同集团企业合并共享母公司信息，但子公司自身字段分开记；
- 超过 50 行时先跑 5 行样例给用户看格式，确认后再全量。
