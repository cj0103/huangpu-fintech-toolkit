## 通用判定总则

1. **看业务本质，不看名称与经营范围**：企业名带"金融科技/数字科技"不等于属金融科技；经营范围罗列不等于实际业务。以主营收入和核心产品为准。**判定所依据的事实（客户、产品、牌照、规模）应来自企业填报说明或公开可信信息，不得由 AI 推测补全；事实不足以判定时，输出"信息不足"并列出需要填报单位补充的问题清单。**
2. **服务对象优先于技术栈**：同一家技术公司，服务金融机构归技术类（B/D），自身直接经营金融业务归应用类（A）。
3. **应用与技术的区分**：直接面向终端客户经营金融业务（哪怕用了很强技术，如互联网保险公司）→ A 类；向金融机构输出技术产品/服务 → B/D 类。
4. **底层技术进金融场景要归位**：AI/云/区块链公司若核心产品直接服务金融场景，除归 D 类外应给出 A/B 类备选，供招引口径选择。
5. **关联度与分类解耦**：先判"做什么、跟金融多近"（关联度），再判"归哪一类"（分类）。
6. **兜底**：核心业务与金融无实质关联（无金融客户、无金融场景产品）→ 判"非金融科技/建议归其他"，并写明缺口理由。
7. **主归类唯一**：每家企业给且仅给一个主归类（填报勾选口径），备选类最多两个，仅作参考、不得重复计入统计。主归类按"主营业务实质"定，备选按"次业务或技术供给面"定。

# 一、应用场景层（A：金融科技直接落在金融业务场景的产品与服务）

## A01 财富管理

- **一句话定义**：面向机构或个人提供财富管理、资产管理和智能投顾的产品与运营服务，含传统资管机构的数字化展业平台。
- **口径要点（国际→全国→上海）**【图谱】：
  - **国际**：以《欧洲投资与养老金》全球资管 500 强、F6S 英国金融科技百强、国信证券全球智能投顾全景图为榜单基准，核心指标资产管理规模（AUM）。国际范式=低费率指数化 + 智能投顾 + 投顾工具开放。
  - **全国**：以毕马威中国金融科技企业双 50、人大财富管理机构公募类产品保有规模 Top100 为榜单基准。
  - **上海**：全国财富管理总部高地之一，特色=要素市场驱动的资管集群 + 互联网财富平台区域总部。
- **标志性企业（判别锚点，不区分注册区）**：
  - 国际：先锋 Vanguard、嘉信 Schwab、富达 Fidelity（美国大众财富管理）、Wealthfront（智能投顾）、Flagstone（英国多管理人财富平台）【图谱】
  - 全国：中国人寿资产、易方达基金、招商银行、蚂蚁基金、天天基金、盈米基金【图谱】
  - 上海：浦发银行、平安资产、壹账通、华泰资管、东方财富、腾富信息（理财通运营）、国泰海通资管、汇添富基金、东证资管、兴证全球基金、信银理财【图谱】
- **典型业务**【推定】：公募/券商资管/保险资管产品管理；银行理财子公司；第三方基金销售与代销平台；智能投顾与投研工具；家族办公室与高净值财富规划；财富管理 SaaS（投顾展业、客户资产配置系统）。
- **关键词信号**【推定】：资产管理、财富管理、基金销售/代销、理财子、智能投顾、投顾、AUM、FOF、资产配置、私人银行。
- **易混淆与区分**：
  - vs A03 另类投资：按**管理人管理对象**区分——公募、券商资管、保险资管、银行理财子、销售平台归 A01；证券私募管理人归 A03。
  - vs A09 企业财务管理：为企业提供财务/财税软件的不是财富管理。
  - vs B03 数据治理开发：万得类金融数据终端为投研提供数据，归 B03，不归 A01。
  - 银行/券商的传统存贷汇与经纪业务本身不算财富管理赛道，除非其主体是财富/资管条线子公司。
- **关联度基准**：直接经营资管/销售业务 → A；财富管理软件商（有金融机构客户）→ B。

## A02 保险科技

- **一句话定义**：以数字化方式经营保险业务，或为保险机构提供投保、理赔、风控、健康管理等科技方案。
- **口径要点（国际→全国→上海）**【图谱】：
  - **国际**：以福布斯美国金融科技 Top50、CB Insights 全球保险科技 50 强、Fintech Global 全球保险科技百强为榜单基准，指标保费、市值。国际范式=场景化碎片保险 + AI 核保理赔。
  - **全国**：以《中国保险年鉴（2024）》（国家金监局）、毕马威双 50 为榜单基准。
  - **上海**：总部型险企科技条线 + 养老金融数字化集聚。
- **标志性企业（判别锚点，不区分注册区）**：
  - 国际：Lemonade（AI 理赔）、Hippo（智能家居保险）、Next Insurance（中小企业险）、Zego（灵活用工险）、Acheel（法国 AI 核保）【图谱】
  - 全国：众安在线、泰康在线、蚂蚁保、腾讯微保、暖哇科技、车晓科技【图谱】
  - 上海：长江养老、致保科技、中科软（保险 IT）、太保科技、交银保险资管【图谱】
- **典型业务**【推定】：互联网保险公司；保险网络销售平台/专业代理；车险 UBI 与定损科技；保险核心系统与健康管理的科技服务；相互保险、共保体数字化。
- **关键词信号**【推定】：保险科技、InsurTech、互联网保险、保险代理/经纪、理赔、定损、保费、健康险、共保。
- **易混淆与区分**：
  - vs A01 财富管理：兼营"险资理财"主体按主营判断；储蓄型保险销售平台偏 A02。
  - 纯传统保险中介（无线上化、无科技能力）→ 关联度 C。
- **关联度基准**：互联网保险公司、保险科技方案商 → A；传统保险中介做线上化 → B；一般保险代理 → C。

## A03 另类投资

- **一句话定义**：以量化策略为管理核心的私募证券投资，含主观策略的另类私募管理人。
- **口径要点（国际→全国→上海）**【图谱】：
  - **国际**：图谱无量化专项榜单，对标全球多策略/量化对冲基金，指标全球量化基金总 AUM。国际范式=多策略平台 + 量化研究工业化的另类资管。
  - **全国**：以排排网《上海量化私募地图》为榜单基准，指标量化私募规模。
  - **上海**：全国量化私募第一城，头部管理人高度聚集。
- **标志性企业（判别锚点，不区分注册区）**：
  - 国际：桥水 Bridgewater、AQR、千禧 Millennium、英仕曼 Man Group、Acadian【图谱】
  - 全国：幻方、九坤、灵均、世纪前沿【图谱】
  - 上海：明汯、衍复、宽德、诚奇、黑翼【图谱】
- **典型业务**【推定】：量化私募（指数增强、CTA、市场中性、高频）；多策略对冲；主观多头与事件驱动私募；另类资管（大宗商品、宏观策略）私募管理人。
- **关键词信号**【推定】：量化、指增、CTA、市场中性、高频、对冲、私募基金管理人、多策略、夏普。
- **易混淆与区分**：
  - vs A01 财富管理：按管理人管理对象区分（证券私募→A03，公募/资管/理财子→A01）。
  - 为量化机构提供数据/交易系统的科技公司 → 归 B03/D01，不归 A03。
  - 私募股权/创投基金 → 归 E03（按管理对象是股权还是证券划分）。
- **关联度基准**：证券私募管理人 → A。

## A04 数字银行

- **一句话定义**：纯线上或深度数字化的银行形态，含互联网银行、民营银行的数字业务，以及为银行数字化提供整体方案的银行系科技公司。
- **口径要点（国际→全国→上海）**【图谱】：
  - **国际**：以 F6S 英国金融科技百强、《亚洲银行家》全球前 100 数字银行为榜单基准，指标客户数、资产规模。国际范式=无网点移动优先银行 + 场景金融嵌入。
  - **全国**：以中关村互联网金融研究院《中国金融科技竞争力报告》为榜单基准。
  - **上海**：图谱显示暂无全国性数字银行法人主体落地（"/"），以银行数字化条线和银行系科技子公司为主。
- **标志性企业（判别锚点，不区分注册区）**：
  - 国际：Revolut、Monzo、Zopa（英国挑战者银行）、Chime（美国）、N26（德国）【图谱】
  - 全国：微众银行、网商银行、新网银行、中信百信银行【图谱】
  - 上海：无全国性数字银行法人（可关注银行系科技子公司在沪布局）【图谱】
- **典型业务**【推定】：互联网银行/直销银行；数字信贷与消费贷款的银行侧运营；银行系金融科技子公司（输出核心系统与数字化能力）；开放银行 API 平台。
- **关键词信号**【推定】：互联网银行、直销银行、数字银行、开放银行、消费信贷、助贷、银行科技子公司。
- **易混淆与区分**：
  - vs B01 金融基础设施：银行牌照机构归 A04，清结算组织归 B01。
  - vs D01 人工智能：以 AI 客服、AI 风控切入银行的方案商 → D01（备选本类）。
  - 助贷/融担/小贷等非银放贷机构 → 图谱未单列，建议按"金融科技关联但类目待议"标注，谨慎处理。
- **关联度基准**：数字银行主体 → A；银行数字化服务商 → B（主归 D 类技术小类）。

## A05 跨境转账

- **一句话定义**：跨境支付、跨境收款与汇款服务，服务对象是跨境电商、外贸企业与个人跨境资金往来。
- **口径要点（国际→全国→上海）**【图谱】：
  - **国际**：以 F6S 英国金融科技百强、FXC Intelligence《全球跨境支付 100 强》为榜单基准，指标处理交易额。国际范式=多币种账户 + 低费率实时汇款。
  - **全国**：以中关村金融科技竞争力报告、FXC 全球跨境支付 100 强、贸促会跨境电商重点联系企业名录为榜单基准。
  - **上海**：B2B 外贸收款头部聚集，全国跨境支付总部高地。
- **标志性企业（判别锚点，不区分注册区）**：
  - 国际：PayPal、西联 Western Union（传统汇款）、Remitly、Wise（低费率跨境）、TransferGo【图谱】
  - 全国：拉卡拉、连连银通、乒乓智能、联动优势、新大陆数字技术【图谱】
  - 上海：蚂蚁国际（万里汇）、寻汇信息科技、XTransfer（夺畅网络）【图谱】
- **典型业务**【推定】：跨境收款平台（B2C 电商卖家收款、B2B 外贸收款）；跨境汇款与薪酬发放；跨境支付清算通道服务；结售汇与汇率风险管理服务。

- **典型业务**【推定】：证券/期货/保险交易所；清算所与支付清算系统（银联、网联、CIPS）；登记托管（中债登、中证登、中信登）；数据报告库；股权托管交易中心。
- **关键词信号**【推定】：交易所、清算、结算、登记、托管、报告库、清算机构。
- **易混淆与区分**：本类基本是持牌基础设施，判定争议少；注意支付清算组织（银联、城银清算）归本类，其成员银行的支付业务归 A06。
- **关联度基准**：基础设施运营主体 → A（天然核心）。

- **关键词信号**【推定】：核心系统、中间件、信创、分布式架构、金融 IT、系统集成、国产化替代。

# 三、底层技术层（D：通用技术底座，判定关键在"是否有金融场景落地"）

## D04 密码技术

# 八、校准与依据标注规则（保证"照此填报"经得起检验）

1. **每条标注注明来源等级**：
   - 【图谱】——直接来自产业图谱原文（定义、榜单、指标、代表企业）；
   - 【推定】——从图谱所列代表企业的公开业务反推的典型业务与关键词，属合理展开；
