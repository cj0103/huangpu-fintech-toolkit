# 企业介绍成稿手册（十项式，包内自包含）

适用：招引月报"项目基本情况"列（线索表/落地表同构十项）的填报指导与成稿。

## 十项模板与写法标准

| # | 项 | 成稿标准 |
|---|---|---|
| 1 | 线索来源 | 如实；活动/渠道名写全（该列通常由申报方自填，AI 留"待补充"） |
| 2 | 股东背景 | 实控链条到自然人/国资主体；只写工商可核信息 |
| 3 | 总部所在地 | 注册地与实际总部区分写 |
| 4 | 行业地位 | 强断言挂出处（榜单全名+发布方+年份）；无出处降级为"XX领域从业者/成长型企业" |
| 5 | 所获资质 | 认定主体+年度；持牌主体写牌照全称（如"中国人民银行《支付业务许可证》"） |
| 6 | 主要业务 | **核心项**，按下方句式库成稿 |
| 7 | 市场竞争力 | 从"产品代差/牌照/客户资源/成本"四类选有证据的写，逐条对应信息卡 |
| 8/9 | 上下游 | 写行业名+代表企业类型；与第 6 项业务链自洽 |
| 10 | 代表客户 | 只写可公开客户；涉密写"国有大行、头部券商等（名录备查）" |

缺项 → 输出"缺项清单+向企业追问的原话"，不代填。

## 措辞纪律（硬约束）

AI 回填/输出的文字**不指涉具体申报主体**（不写"街道/报送单位/部门"等称谓，
更不写具体街道名）：信息缺口一律写"待补充"；确需说明补数来源时写"由申报
单位补充"或径写"待补充"。信息出处表述用中性口径（"工商公示口径/公开报道/
填报材料口径"），不用"街道口径"。

## 第 6 项句式库（引用 taxonomy.md 各类目参考句式）

统一骨架：**「以【技术手段】面向【金融场景】提供【产品/服务】，服务【客户类型】，
规模/指标【X】」**。按 S3 关联度分档成稿：

- **A/B 档（有金融证据）**：直接成稿。量化位取该类目行业核心指标
  （AUM/保费/处理交易额/落地机构数等，见 taxonomy 口径要点）。
- **B/C 边界（有技术、金融客户证据单源）**：成稿但金融客户降级为
  "已服务XX等机构（待核实）"，并出提示："请确认金融客户全称与合作内容"。
- **C 档（无金融客户证据）**：如实写实际业务，句末不加金融包装；附提示
  "当前公开信息未见金融科技实质属性，若企业确有金融场景业务请补充证据"。
- **D 档**：如实写真实产业属性 + "建议与报送单位核实是否计入金科口径"。

**改写示例（对照训练样本）**：
- 原：某信息科技公司"提供数字支付科技、供应链金融科技等服务"→ 成稿应具体化：
  "以自研『中保付』平台面向保险行业支付结算场景提供资金归集与分账服务，
  服务国内保险机构 XX 家"（技术、场景、产品、客户四要素齐）。
- 反例：食品电商代运营企业 → 不得为靠拢"行业支撑服务"而包装；出 D 档提示。

## 依据表（强制输出，不可关闭）

成稿后逐句列表：`成稿句 | 信息卡字段 | 来源（URL/材料+日期） | 标注（✅/⚠️/❓）`。
⚠️/❓ 句在成稿中用括号注明"待核实"或删句。

## 文字风格（继承接待材料文风标准）

正式平实；鲜活来自具体（数字、产品名、客户类型），不来自修辞；
删除"赋能新标杆/行业翘楚"式空话；一段一主题。

## 输出形态

- **表单模式**：openpyxl 复制原表 → 每 sheet 右侧追加 7 列（AI建议赛道 /
  备选 / 置信度与追问 / AI建议星级 / 星级理由 / 描述改写建议 / 依据与疑问）。
  追加列设浅色底纹区别于原表；文件 `【AI辅助】原名-YYYYMMDD.xlsx`；
  原文件只读绝不覆盖。
- **单企复核卡**（仅名称模式）：Markdown 五段=一句话画像 / 信息卡摘要表 /
  赛道判定（含依据链）/ 十项成稿 / 依据表+追问清单。
- **docx 交付**（用户明确要求时）：公文风参数写死——标题方正小标宋简体 22pt 居中；
  正文仿宋_GB2312 16pt（三号）；一级标题黑体、二级楷体_GB2312；行距 28 磅；
  页边距 上3.7/下3.5/左2.8/右2.6 cm；直接 python-docx 生成，不引其他 skill。
