# huangpu-fintech-toolkit · 金融科技招引填报辅助器

## 这个工具是干什么的

一个 AI 技能（Skill），用于金融科技企业招引填报场景，帮使用者做两件事：

1. **抓取公开信息**：给它一个企业名称（或一张招引表单 xlsx），它自动通过
   公开渠道——监管公示（央行支付业务许可公示、行业协会备案名单等）、
   工商公示、企业官网、公开报道——搜集该企业的工商基本面、资质牌照、
   产品业务、金融客户证据、关联公司与风险信息，整理成结构化"企业信息卡"；
2. **选择合适分类**：对照内置的"四大类 × 22 小类"金融科技赛道标注库
   （taxonomy），为每家企业给出主赛道建议、备选赛道、与金融科技的关联度
   （A 核心 / B 紧密 / C 弱 / D 非金科）、重要度星级建议，并按"十项式"
   模板起草可直接填报的企业基本情况介绍。

结果可按原表结构回填 Excel（原文件不动，产出【AI辅助】副本），也可以
单企复核卡（Markdown/docx）形式交付。表单模板变化（列名、列序、sheet
结构调整）由内置的表头自适应层处理，无需改工具本身。

## 重要声明：仅供参考，不能代替人工核查

**本工具的全部输出均为辅助参考草稿，不能代替人工的信息核查与核对。**

- 工具只接触**公开渠道信息**，公开信息可能滞后、残缺、同名混淆或本身有误；
  工具虽内置溯源标注（✅有出处 / ⚠️单源待核 / ❓未查到）与逐句依据表，
  但这只是把"哪里需要人工把关"标出来，**不等于内容已经核实**；
- 赛道归类、关联度、星级均为**模型基于内置规则的建议**，不构成投资、
  监管、统计或行政认定依据；正式填报前，应由熟悉企业的经办人对
  股东背景、资质牌照、客户与业务表述等关键事实**逐项人工核实**；
- 凡带 ⚠️/❓ 标注的内容，未经核实不得写入正式报表；工具对 D 档
  （非金融科技）企业输出的警示仅为提示，采信与否由使用方判断；
- 请勿将企业非公开信息（联系人、自报财务数据、内部推进记录等）提供给
  本工具写入档案或对外产物。

## 核心设计

- **22 类赛道标注库**（`references/taxonomy.md`）：每类目含定义、国际/全国/
  上海三层标志性企业锚点、典型业务、关键词、易混淆区分、关联度基准——
  判定读库，不靠模型即兴；
- **关联度与分类解耦**：先判"跟金融多近"，再判"归哪一类"；
- **四因子星级模型**：赛道契合 35 / 主体分量 25 / 背景与落地性 25 /
  战略稀缺 15；企业自报营收税收不参与打分，失配时输出数据存疑提示；
- **真实性铁律**：逐条溯源、三档标注、禁止推测填空、成稿逐句依据表
  （不可关闭）；
- **表头自适应**：不假设 sheet 名与列序，按语义角色识别表头；
  conserv（旁列复核）/ fill（空表直填）/ merge（对照改写）三种模式；
- **自包含**：不依赖任何其他技能，调研/判定/成稿规则包内写死。

## 使用方式

放入 WorkBuddy 技能目录（`~/.workbuddy/skills/huangpu-fintech-toolkit/`）后：

- 单企："帮我查一下 XX 公司，判断属于哪个金融科技赛道"
- 表单："这张招引月报帮我复核（或代填）赛道和企业基本情况"
- 批量："开全库复核模式，跑一遍这份汇总表"


## 口径校准提示

22 类目口径基于公开产业图谱整理并含合理补全（E04 金融科技咨询服务），
使用方应以自身报表类目的官方定义为准做一次映射校准。
